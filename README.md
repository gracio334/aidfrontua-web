# 🇺🇦 AidFrontUA — Global Ukraine Support & Humanitarian Aid Directory

**Live Portal:** [https://aidfrontua.com](https://aidfrontua.com)

**AidFrontUA** is a free, open-source, community-driven web directory built to centralize verified humanitarian aid programs, refugee support resources, volunteer initiatives, and curated war log news feeds in one fast, accessible place.

---

## ✨ Key Features

- **Searchable Aid Directory:** Easily browse and filter humanitarian support programs across multiple categories and regions.
- **Public Program Submissions:** NGOs, grassroots groups, and verified volunteers can submit new initiatives directly through the portal's submission form.
- **Curated War Log Feed:** Stay informed with structured news updates alongside active support resources.
- **Privacy-First & Lightweight:** Zero ads, zero paywalls, and no invasive tracking cookies.

## 🛠️ Tech Stack

- **Frontend:** Static Web (HTML / CSS / JS) deployed on **Cloudflare Pages**
- **Database & CMS:** **Baserow** (API-driven structured records & form submissions)
- **Version Control & CI/CD:** **GitHub**

## 🤝 How to Contribute

1. **Submit an Aid Program:** Visit [aidfrontua.com](https://aidfrontua.com) and use the public submission form to list a verified initiative.
2. **Improve the Codebase:** Found a bug or have an idea to improve accessibility, translations (EN/UK/PT), or filtering? Feel free to open an **Issue** or submit a **Pull Request**.
3. **Spread the Word:** Share the directory with organizations, volunteers, and communities supporting Ukraine.
